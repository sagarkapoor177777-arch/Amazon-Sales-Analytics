# Amazon-Sales-Analytics
# 🛒 Amazon Sales Data Analytics | End-to-End ETL & BI Project

An end-to-end **Data Analytics project** built using an Amazon sales dataset to analyze sales performance, orders, products, fulfilment, sales channels, shipping geography, and order status.

This project demonstrates a complete real-world data analytics workflow:

**Raw Data → ETL → Data Cleaning → Data Validation → SQLite Database → SQL Analysis → Python EDA → Visualization → Power BI Dashboard → Business Insights**

---

## 📌 Project Overview

The main objective of this project is to transform raw e-commerce sales data into meaningful business insights using Python, Pandas, SQLite, SQL, Matplotlib, Seaborn, and Power BI.

The project covers:

- Data extraction and preprocessing
- ETL pipeline development
- Data cleaning and transformation
- Data quality validation
- Missing-value and duplicate handling
- Invalid-record identification
- Rejected-record handling
- SQLite database creation
- SQL business analysis
- Exploratory Data Analysis (EDA)
- Data visualization
- KPI analysis
- Interactive Power BI dashboard
- Business insights and recommendations
